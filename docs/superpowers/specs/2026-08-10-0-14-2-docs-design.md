# Kata 0.14.2 Documentation Finalization Design

## Goal

Finalize the public changelog for Kata 0.14.2 so the release history records
the shipped Homebrew installation support, SQLite-era Beads import support,
TUI draft protection, and `scheduled_on` time semantics fixes.

## Context

The install, packaging, Beads migration, and metadata pages already describe
the user-facing contracts introduced by this release. The changelog still
labels the release notes as `Unreleased` and does not mention SQLite-era Beads
imports or the `scheduled_on` correction.

## Chosen approach

Update `docs/changelog.md` only. Rename the current `Unreleased` heading to
`0.14.2`, add the release date `2026-08-10`, preserve the existing release
notes, and add the two missing entries under the matching feature and bug-fix
sections. Do not regenerate the built site or rewrite pages that already
describe the shipped behavior.

## Verification

- Run the repository's documentation check.
- Confirm the changelog contains all four requested release items and no
  `Unreleased` heading remains for this release block.
- Review the final diff and run the repository privacy scan before publishing.

## Scope boundary

This change does not alter application behavior, persisted data, migrations,
generated site output, or release automation.
